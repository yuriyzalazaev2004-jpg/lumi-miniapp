# LUMI 5.1 — установка

## Перед началом

Сохраните резервную копию репозитория и экспорт важных таблиц Supabase. В архиве — полный репозиторий, а не только патч. Установка изменяет фронтенд и две Edge Functions. Не удаляйте существующие таблицы.

## 1. SQL

Supabase → SQL Editor → New query → вставьте и выполните `supabase/sql/05_lumi_51.sql` **один раз**. Предполагается, что SQL версии 5.0.2 уже применён. Скрипт сохраняет прежние таблицы и переносит один старый баннер в список кампаний, если список пуст.

## 2. Edge Functions

Supabase → Edge Functions → `lumi-admin` → Code: замените `index.ts` на `supabase/functions/lumi-admin/index.ts`, затем Deploy. Verify JWT оставьте OFF; Telegram initData проверяется функцией.

Supabase → Edge Functions → `telegram-webhook` → Code: замените `index.ts` на `supabase/functions/telegram-webhook/index.ts`, затем Deploy. Verify JWT оставьте OFF **только при действующей проверке** заголовка `X-Telegram-Bot-Api-Secret-Token` и сохранённом `TELEGRAM_WEBHOOK_SECRET`.

Обе функции используют существующие Supabase Secrets: `TELEGRAM_BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`; webhook также использует `TELEGRAM_WEBHOOK_SECRET`. **Не вставляйте значения секретов в исходный код.**

## 3. GitHub

Обновите файлы из корня репозитория (в первую очередь `src.jsx` и `style.css`). Серверные файлы `supabase/` хранятся в репозитории как резервная копия; их загрузка в GitHub сама по себе НЕ разворачивает Edge Functions. Дождитесь завершения GitHub Actions Pages.

## 4. Проверка

1. Откройте приложение внутри Telegram (не в обычном браузере). Проверьте прежние разделы и облачную синхронизацию.
2. Админка: создайте две кампании, добавьте фото, включите, проверьте главную, клики и удаление выбранной кампании.
3. Вторым аккаунтом откройте бота, нажмите Start, отправьте форму «Сотрудничество», затем обычное сообщение боту. В админке нажмите «Загрузить историю переписки» и отправьте ответ.
4. Выполните новую задачу: XP +10. Перезагрузите: повторное выполнение того же ID не должно давать дополнительные XP. В профиле включите участие в рейтинге.
5. Проверьте раздел «Аналитика» после открытия разных разделов.

## Ограничения и безопасность

- Это сборка для **проверки на тестовых аккаунтах**, не результат живого end-to-end теста. Сборка через Vite не запускалась: npm-зависимости недоступны в офлайн-кэше. Синтаксис JSX/TS проверен компилятором TypeScript.
- Статистика показов приблизительная: учитываются открытия главной, есть минутная дедупликация; блокировщики и сетевые сбои могут влиять на счётчики. Данные в отчётах ограничены последними 10 000 событиями; для большого трафика нужны серверные агрегаты.
- XP защищены от **повторного начисления по одному ID задачи**, но не от подделки новых ID клиентом. Перед денежными наградами или призами нужна серверная проверка факта выполнения задачи.
- Рейтинг по умолчанию выключен, отображается нейтральное имя «Участник». Чаты доступны только владельцу, личные финансы не выводятся в аналитику.
- Изображения старых удалённых кампаний могут оставаться в Storage; автоматическая очистка файлов из Storage в этом обновлении не реализована.
- Удаление кампании удаляет связанные события статистики из базы (`ON DELETE CASCADE`). Если нужна историческая отчётность, сначала экспортируйте её.
- `telegram-webhook` принимает сообщения только от пользователей, ранее отправивших обращение в приложении; другие сообщения бот не сохраняет.
