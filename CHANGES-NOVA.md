# LUMI NOVA — новая визуальная система

Переработаны JSX-разметка и стили главной, календаря, финансов и привычек.
Новые блоки: обзор задач, финансовые карточки, таймлайн, недельный трекер привычек.
Остальные разделы сохранены и приведены к общей дизайн-системе.
Форма долга содержит название, сумму, погашение, контрагента и кнопку сохранения.

Сохранение сначала локальное, затем фоновая синхронизация через cloud-sync.js.
Работа Supabase и Telegram на живом сервере не проверена. Не удаляйте данные и таблицы.
Для установки замените файлы репозитория содержимым папки и дождитесь успешной сборки GitHub Actions.
