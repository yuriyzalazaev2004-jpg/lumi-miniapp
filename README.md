# LUMI — новая чистая сборка

Это **переписанный с нуля интерфейс**. Старые файлы стилей и компоненты удалены.

## Установка

1. Сделайте резервную копию репозитория и данных.
2. Удалите старые файлы из GitHub-репозитория (кроме `.git`, если работаете локально).
3. Скопируйте **содержимое** папки `lumi-miniapp-main/` в корень репозитория. Не загружайте папку целиком как вложенную.
4. Дождитесь завершения GitHub Actions.
5. Перезапустите Telegram Mini App.

## Что перенесено

Главная, календарь, финансы, долги (создание, редактирование, удаление, погашение), задачи, привычки, цели, список покупок, тренировки, дни рождения, регулярные платежи, базовая аналитика, профиль, темы.

## Что пока НЕ перенесено

Старые расширенные разделы холодильника/рецептов, календаря цикла, спортивных программ, админ-панели, рекламы, XP и напоминаний. Данные в Supabase и localStorage не удаляются, но часть старых данных не показывается новым интерфейсом. Не удаляйте старую резервную копию.

## Важное о сохранении

Сохранение сначала производится локально, после чего `cloud-sync.js` пытается синхронизировать с Supabase. Индикатор облака в шапке показывает состояние синхронизации. **Облачное сохранение не проверено** на вашем Supabase. Для него серверная функция `lumi-sync` должна разрешать все ключи из `DATA_KEYS`.

## Проверка

Автоматическая Vite-сборка в рабочей среде не завершена из-за недоступной установки npm-зависимостей. После загрузки проверьте статус GitHub Actions до открытия Mini App.
