# LUMI

Telegram Mini App для планирования дня, учёта финансов, привычек, целей, запасов и питания.

## Локальный запуск

В CI используется Node.js 22.

```bash
npm ci
npm test
npm run build
npm run dev -- --port 4173 --strictPort
```

Vite обслуживает приложение по пути `/lumi-miniapp/`. В обычном браузере можно пользоваться локальным профилем. Для проверки облака и напоминаний откройте приложение через бота в Telegram с действительной сессией.

## Структура

- `src.jsx` управляет запуском, навигацией, Telegram и темой.
- `app/` содержит экраны, общие компоненты, формы и модель данных.
- `app.css` задаёт токены светлой и тёмной тем и учитывает безопасные области Telegram.
- `recipes-ru.js` содержит каталог рецептов.
- `cloud-sync.js` синхронизирует существующие ключи через Edge Function с проверкой версии записи.

## Данные и интеграции

Telegram-сессия проверяется функцией `telegram-auth`. `lumi-sync` отвечает за доступ к облачным записям и проверку версии на сервере. `lumi-admin` принимает список событий и настройки Telegram-напоминаний. Репозиторий содержит клиентский код этих интеграций. Для интеграционных проверок потребуются работающие Edge Functions, бот и тестовые аккаунты Telegram с разрешением на сообщения. Напоминание о привычке обновляется при открытии приложения и синхронизации на текущий день. Повторяющиеся доставки при закрытом приложении зависят от серверного расписания.

Данные каждого подтверждённого Telegram-профиля записываются отдельно. При обнаружении старых локальных ключей приложение предлагает перенести записи в аккаунт. Исходные записи сохраняются. Перед переносом проверьте, что эти записи принадлежат открытому аккаунту. Серверные ключи и форматы сохранены. Схема базы данных не менялась.

Для проверки с двумя тестовыми аккаунтами создайте запись в первом, откройте его на втором устройстве, измените и удалите запись. Затем войдите под другим аккаунтом и проверьте, что запись отсутствует. Отдельно проверьте получение сообщения после настройки напоминания и предоставления разрешения боту.
