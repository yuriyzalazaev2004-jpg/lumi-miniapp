# LUMI — Telegram Mini App (MVP интерфейса)

## Что готово
- React/Vite адаптивное мини-приложение с двумя темами (и авто-темой Telegram)
- Главная страница, календарь, финансы, кухня, здоровье, тренировки, дни рождения, учёт времени, статистика
- Создание/удаление/отметка выполнения записей, фотографии (до 1,2 МБ), ссылки, даты, суммы, категории долгов, количество продуктов и сроки годности
- Данные пока хранятся в localStorage **только на устройстве**. Это демонстрационная версия, а не production.

## Запуск локально
1. Установите Node.js 20+.
2. В папке проекта выполните `npm install`.
3. Запустите `npm run dev`.
4. Откройте адрес, который покажет Vite.

## Размещение бесплатно
1. `npm run build` создаст папку `dist`.
2. Разместите содержимое `dist` на GitHub Pages, Cloudflare Pages или другом HTTPS-хостинге (с учётом лимитов бесплатного тарифа).
3. Через @BotFather создайте бота и настройте кнопку меню Mini App с публичным HTTPS URL.
4. Для полноценной работы требуются Supabase с RLS и серверный бот/планировщик Telegram-уведомлений.

## Важно
- **Пока нет реальных Telegram-уведомлений, серверной синхронизации, автоповторов, рецептов и защищённого хранения чувствительных данных.**
- Не вводите в демо реальные конфиденциальные сведения: данные сохраняются в браузере, не шифруются отдельно и могут исчезнуть при очистке браузера.
- Telegram `initDataUnsafe` подходит только для отображения имени. Для авторизации на сервере необходимо проверять подписанный `initData`.
- Не включайте чувствительные данные здоровья в рекламные профили.
