LUMI — ЕДИНЫЙ CSS + ОБНОВЛЕНИЕ ГЛАВНОЙ

Это полный проект для замены в GitHub, не отдельные файлы-патчи.
Удалены 11 устаревших CSS-файлов. Стили собраны в lumi-core.css, а новые визуальные правила — в lumi-design.css.
Сохранены компоненты и интеграция Supabase. В форме названия явно включен текстовый ввод.

ВАЖНО: не удаляйте Supabase/таблицы. Это не полноценная переписанная версия приложения и не доказательство исправления серверной синхронизации.

Установка: сделайте резервную копию репозитория; замените ВСЕ файлы репозитория содержимым папки lumi-miniapp-main, включая удаления; дождитесь завершения GitHub Actions и откройте приложение заново.
